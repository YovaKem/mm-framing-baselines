# Annotated examples

Three sampled articles shown end-to-end: the original image and text, and the
final target labels — the text frame is the silver-standard 2-of-3 consensus
across the LLM labeling ensemble, and the image frame is real ground truth,
the paper's own human double-annotation (not an ensemble vote).

- [`example_1_overlap.md`](example_1_overlap.md) — text and image frames overlap
- [`example_2_divergent.md`](example_2_divergent.md) — the image conveys a frame the text doesn't
- [`example_3_neutral_image.md`](example_3_neutral_image.md) — the image has no frame ("None")
